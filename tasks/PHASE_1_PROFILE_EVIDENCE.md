# Phase 1 Task — Profile and evidence

Do not start until Phase 0 acceptance criteria pass.

## Objective

Build a versioned professional profile and an atomic evidence library that can safely ground future matching and application generation.

## Vertical slice

- create/edit a draft profile;
- define hard constraints and preferences;
- add evidence items with provenance and verification status;
- publish an immutable profile version;
- show completeness and conflicts;
- seed only clearly synthetic development data;
- test ownership, versioning and validation.

## Key safety rule

Imported or model-extracted facts remain unverified until the user confirms them.
